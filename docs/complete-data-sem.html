Borrelia Competence of Peromyscus

Complete data SEM

Figure 18 visualizes a SEM fit to a “complete” data set (i.e., only observations for which all variables were measured). As such, it has some limitations in its power, but it is the most “defensible” explanatory model because it does not draw conclusions beyond the scope of its data. Models using more of the data will be explored in the next section.

While this model is very interesting, one of the primary paths of interest is not significant (behavior -> ticks -> resistance -> burden -> tolerance). It is possible that the “behavior -> ticks” path is improved by a model which is not limited by the completeness restriction. Table 11 summarizes the fit (r^2) of each of the component models.

Figure 18: Acyclycal graph diagram of selected SEM model, fit with complete cases. The goodness-of-fit P-value is 0.88, which indicates that this model is not statistically different from an ‘ideal’ model of these data.
